# 强化学习迷宫导航作业

这是一个强化学习实践作业，你需要实现Q-Learning和SARSA两种算法来训练智能体在迷宫环境中导航。

## 📁 项目结构

```
├── environment.py    # 迷宫环境和可视化（无需修改）
├── q_learning.py     # Q-Learning算法框架（需要完成TODO部分）
├── sarsa.py          # SARSA算法框架（需要完成TODO部分）
├── train.py          # 训练和测试接口（无需修改）
└── README.md         # 本文件
```

## 🎮 环境说明

迷宫是一个5×5的网格，包含：
- **白色方块**：空地（安全移动）
- **红色方块**：陷阱（-50奖励，回合结束）
- **黄色方块**：目标（+100奖励，回合结束）
- **黑色圆圈**：智能体（从左上角开始）

## 📝 作业要求

### 1. Q-Learning算法实现（`q_learning.py`）

Q-Learning是一种off-policy算法，学习最优Q函数：

**更新规则：**
```
Q(s,a) = Q(s,a) + α * [r + γ * max_a' Q(s',a') - Q(s,a)]
```

**需要完成的任务：**
1. 在`QLearningAgent`类中实现`learn()`方法
2. （选做）尝试不同的探索策略

### 2. SARSA算法实现（`sarsa.py`）

SARSA是一种on-policy算法，学习执行策略的Q函数：

**更新规则：**
```
Q(s,a) = Q(s,a) + α * [r + γ * Q(s',a') - Q(s,a)]
```

**需要完成的任务：**
1. 在`SARSAAgent`类中实现`learn()`方法
2. （选做）尝试不同的探索策略

## 🔍 关键概念

### 状态表示
- 状态用元组`(row, column)`表示智能体位置

### 动作空间
- 4个离散动作：0=上, 1=右, 2=下, 3=左

### 奖励设计
- 到达目标：+100（回合结束）
- 踩到陷阱：-50（回合结束）
- 每步移动：-1（鼓励走最短路径）

### 探索与利用
- 使用ε-贪婪策略
- ε随时间从1.0衰减到0.01
- 测试时ε设为0（纯贪心策略）
